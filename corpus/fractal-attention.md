# Fractal attention

My attention doesn't go linearly through a list. It zooms: a single word in a paper opens onto a whole field, then snaps back out to the project, then dives into an unrelated cell.

This is not a bug to manage but a motion to support. The tool should treat zoom as the primary verb, not search.
