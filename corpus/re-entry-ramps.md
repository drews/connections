# Re-entry ramps

After a context switch, the hardest question is "where was I?" A re-entry ramp answers it without making me re-read everything.

- A breadcrumb trail of *places*, not actions: which constellations I lingered in.
- Kept locally. A trail is mine, not telemetry. See [[Sousveillance not surveillance]].
- At cosmos scale the trail should look like a flight path between territories.
- Pairs with [[Object permanence]].
