# The membrane

Between me and my agents there should be a membrane, not a window. A membrane is selective: it lets some things through at some sizes.

The insight is that **scale is the filter**. An agent at constellation aperture sees the shapes and names of my thinking, but sparks reach it only as counts.

- Each agent gets an aperture: the finest power of ten it may resolve.
- Private notes never resolve below constellation, regardless of aperture.
- It's two-way: I don't watch every agent step either. See [[Agent postcards]] and [[Beacons]].
