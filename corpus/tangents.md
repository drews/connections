# Tangents as side quests

A tangent is not a failure of focus; it's a side quest. Games solved this decades ago: you can wander off, and the main quest marker is still there when you come back.

- Capture the tangent where it happened, so it lands *near* its origin instead of in a junk drawer.
- Let it grow into its own constellation if it keeps getting fed.
