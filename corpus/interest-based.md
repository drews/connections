# Interest-based nervous system

Importance doesn't start my engine; interest, novelty, challenge and urgency do.

A good tool doesn't fight that by nagging about importance. It makes the interesting thing *visible at the right scale*, so the interest gets attached to the work instead of to the nearest distraction.
